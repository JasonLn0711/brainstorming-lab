# Expert Review Questions

## Fast Review Prompt

Please review this packet as a research-direction assessment. The immediate decision is not whether the project is already publishable. The decision is which scientific object, first experiment, and evaluation frame should be protected.

## Core Framing Questions

1. Is the best primary object **knowledge graph compression**, **evidence-preserving context construction**, or **small-model decision stability**?
2. Does the phrase `provenance-preserving KG compression for SLM decision support` describe a meaningful research contribution, or should it be reframed?
3. What would make this direction distinct from GraphRAG, subgraph retrieval, summarization, or agent memory?
4. Which claim is strongest and most defensible for a first paper?

## Method Questions

1. What information must survive graph compression for expert reasoning?
2. Should the compression objective optimize for token budget, answer accuracy, provenance retention, uncertainty preservation, decision stability, or audit cost?
3. What baselines would be considered fair?
4. Should dynamic pheromone-style compression be part of the first experiment or saved for a later paper?
5. Should hidden-state representation be central, or treated as one downstream use case?

## Dataset And Domain Questions

1. Which first domain is most credible?
   - public web evidence provenance;
   - cybercrime/scam-prevention evidence;
   - scientific-paper claim audit;
   - ancient-script symbolic hypothesis ranking;
   - personal/expert external-memory systems;
   - synthetic high-stakes decision workflow.
2. Which domain can produce 30 to 50 clean graph records quickly?
3. Which domain has the least sensitive-data risk?
4. Which domain would reviewers find scientifically meaningful rather than tool-shaped?

## Evaluation Questions

1. How should decision stability be measured?
2. How should provenance retention be scored?
3. How should unsupported claims be identified?
4. Should expert audit time be a primary metric or secondary evidence?
5. What failure mode would convincingly falsify the idea?

## Scope And Boundary Questions

1. What claims should the first study explicitly avoid?
2. What level of evidence is needed before saying that compression improves SLM reasoning?
3. What ethical or governance boundaries matter if the first domain involves scam, cybercrime, health, or personal notes?
4. Should the first artifact be a framework paper, dataset paper, method paper, or systems paper?

## Requested Expert Output

Please return:

- recommended primary framing;
- best first domain;
- minimum viable experiment;
- must-have baselines;
- must-have metrics;
- claims to avoid;
- likely venue or community fit;
- one sentence describing what would make the project publishable.
